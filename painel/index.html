Falta conectar o banco de dados

O painel usa o Supabase (gratuito) para login e para salvar os dados de cada usuário.

  1. Crie um projeto em supabase.com.
  2. Em SQL Editor, cole e rode o arquivo supabase.sql deste repositório.
  3. Em Project Settings → API, copie a Project URL e a anon public key para o arquivo config.js.

Enquanto isso, dá pra testar o painel sem login com dados de exemplo (nada é salvo).
